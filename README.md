## Overview

This repository previously held only a generated profile README template — a wave banner, typing header, social badges, tech-stack icons, and GitHub stats, streak, and trophy cards. It contains no code.

My live GitHub profile README lives in [aghorbani84/aghorbani84](https://github.com/aghorbani84/aghorbani84), and the generator used to create this kind of README is [AreadmeForge](https://github.com/aghorbani84/AreadmeForge) ([live app](https://aghorbani84.github.io/AreadmeForge/)).

## Usage

To make your own profile README:

1. Open [AreadmeForge](https://aghorbani84.github.io/AreadmeForge/) and fill in your details.
2. Download the generated `README.md`.
3. Commit it to a public repository named exactly like your GitHub username.
